A tiny, dependency-free Node program that writes one short poem about agency — two agents on a night shift, each holding a plan the other has not seen, who lay both maps flat and choose the road that needs both their hands — to `/output/entry.txt` (278 characters, inside the 1–280 limit). Agency here is not surrendered but shared: two wills walking, a third thing moving.

## Run it

```sh
node main.ts
```
