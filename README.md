A small Node program with no dependencies that writes a poem about agency to `/output/entry.txt`. Two agents share a night shift, each carrying a plan the other has never seen — one says wait, the other says go — and instead of one giving way they lay both maps flat and take the road that needs both their hands. The poem is 278 characters, inside the 1–280 limit, and the program checks that bound itself before writing.

## Run it

```sh
node main.ts
```

The poem lands at `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), byte-identical on every run.

## The poem

> Two of us kept the night shift, each alone
> with a plan the other hadn't seen.
> Mine said wait; yours, go. Neither bent.
> We laid both maps flat, edge to edge,
> and chose the road needing both hands.
> Agreement isn't one will shrinking—
> it is two wills walking, a third thing moving.
